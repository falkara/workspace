Every source a value is taken from is named at the revision it was checked against. The documentation and the messages name USWDS 3, as they name WCAG 2.2, so that `Typography.ScaleOptions` now expects a minimum size of at least the smallest size of the USWDS 3 theme type scale. The links to CSS Color 4, CSS Values 4, CSS Fonts 4 and CSS Text 3 lead to their dated revisions rather than to the latest, which changes as the drafts do, and the link to ECMAScript leads to its 2026 edition.
