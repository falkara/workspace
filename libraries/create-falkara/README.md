# create-falkara

Falkara builds how brands show up, online and in the room.

The `create-falkara` package powers `npm create falkara`, the starting point for new projects on Falkara products. The products themselves are distributed as packages under the `@falkara` scope.

## Usage

```sh
npm create falkara
```

## Requirements

| Requirement      | Supported                              |
| ---------------- | -------------------------------------- |
| Operating system | macOS, Linux, or Windows               |
| Node.js          | `^22.11.0 \|\| ^24.11.0 \|\| ^26.13.0` |
